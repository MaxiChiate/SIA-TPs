Step 5, training (D-01, course slides p. 16): one order array 0..n-1 reused for all epochs; each epoch calls rng_shuffle on it and visits the rows in that order; a long long step counter s runs from 0 to steps - 1 with fraction = steps > 1 ? s / (steps - 1) : 0 and eta = kohonen_decay(eta0, eta_final, fraction); per sample y = sum_j w_j x_j and then w_j += eta * y * (x_j - y * w_j) for every j with that same y; no renormalization during training. Trace rows: row 0 = epoch 0, eta0, |w| (1 at the start), delta_w 0, then the start weights; row e (e = 1..epochs) = epoch e, the eta of the epoch's last step, |w| before any renormalization, the Euclidean norm of (w at the end of epoch e minus w at the end of epoch e - 1), then the weights at the end of epoch e. After each epoch, if any w_j is not finite print "oja: the weights diverged at epoch <e>; lower eta0" to stderr and return 0. The single Rng passed in drives the start vector and every shuffle, so the seed fixes the run.

Step 6, finish (D-01, D-02): w_norm_final = |w| after the last epoch; delta_w_final = the last trace row's delta_w; divide w by its norm (length 1); orient with a static helper oja_orient(double w[], int n) (exported in Task 2): pivot = the index of the largest |w_j|, a strictly larger |w_j| replaces the current pivot so the lowest index wins a tie; if w[pivot] < 0 negate every component and return 1, else return 0.
