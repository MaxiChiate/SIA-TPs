## Phase Goal

**As a** student, **I want to** validate a Hopfield core on four 5x5 letters, **so that** I understand recovery, energy, capacity and spurious states before moving to QR codes.

<objective>
Run every pre-registered Hopfield experiment on the letters through one guarded driver, cross-check every run in numpy, and aggregate the results the figures and the deliverable read. Task 1 wires one path end to end (guard -> selection -> separated set, async recall -> cross-check -> recall.csv); Task 2 adds the other recall variants, the orthogonality report and both capacity sweeps; Task 3 runs the spurious search and closes the run with run.json and the determinism check.

Purpose: HOP-02 (recall, orthogonality, capacity over several subsets) and HOP-03 (a classified spurious state), computed only from what the user froze in plan 04-03 (D-04).
Output: analysis/hopfield_letters.py, analysis/tests/test_hopfield_letters.py, a make hopfield-letters target, and analysis/results/hopfield/letters/ (generated, not versioned).
</objective>
