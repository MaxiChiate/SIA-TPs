## Phase Goal

**As a** campaign analyst, **I want to** train a Kohonen map of the 50 creators with a grid chosen by a rule fixed beforehand, **so that** I can read creator profiles by region and contrast them with PC1/PC2.

<objective>

One path first: the example config trains a map on the real data and the existing smoke series shows qe and te as summary columns. Then the training trace and both neighborhood kernels are pinned by C tests under the sanitizers, and numpy recomputes every measure the binary reports.

Purpose: every later plan (LOO, stability, selection, figures, profiles) reads these run files; if the C measures are wrong, the grid choice is wrong.
Output: neuron/models/kohonen.c (renamed from the stub), seven strict config keys, occupancy.csv and trace.csv, analysis/som.py with read_run and metrics_from_prototypes, tests in C and pytest, updated READMEs.

## Flagged assumptions (spec-less edge probe)

The edge probe left SOM-01 and SOM-02 `unclassified` / `unresolved`. They are not resolved here; the plan assumes the following edge set and flags it as unverified by the probe:
- **SOM-01 (unresolved, assumption):** the boundaries that matter are k^2 > n at init (k = 6..8 on 50 rows, k = 8 on 49 rows in LOO), the radius at the last step (fp undershoot below 1), a gaussian sigma that could reach 0, eta outside (0, 1), and epochs * n overflow. Each has a validation or a test below; no other edge was searched for.
- **SOM-02 (unresolved, assumption):** TE needs a second BMU (k >= 2 guarantees two neurons); a tie in the second BMU goes to the lowest index; empty neurons count in empty_fraction but never divide by zero because n >= 2 means at least one occupied neuron. No other edge was searched for.

Step 5, schedules and neighborhood (D-01, D-02): static helpers kohonen_decay(start, end, fraction) = start * pow(end / start, fraction); kohonen_radius(radius0, radius_final, fraction) = fmax(kohonen_decay(radius0, radius_final, fraction), radius_final) (the clamp keeps the last steps at radius_final when pow lands one ulp below it, Pitfall 3); kohonen_neighbor_weight(int d2, double radius, int gaussian): step returns 1.0 when d2 <= radius * radius + 1e-12 and 0.0 otherwise (so radius 1 reaches the four adjacent cells and not the diagonals, D-01 uses <=); gaussian returns exp(-d2 / (2 * radius * radius)). Task 2 exports them; here they may stay static.

Step 6, training (D-03): one order array 0..n-1 reused for the epochs; each epoch calls rng_shuffle on it and visits the rows in that order; a step counter s runs from 0 to T - 1 with fraction f = s / (T - 1); eta = kohonen_decay(eta0, eta_final, f); radius = kohonen_radius(radius0, radius_final, f) (one key pair serves as R for step and sigma for gaussian); the BMU comes from nearest(); for every neuron u with integer grid offset (dr, dc) from the BMU, d2 = dr * dr + dc * dc, h = kohonen_neighbor_weight(d2, radius, gaussian); skip u when h is 0; otherwise W_u += eta * h * (x - W_u) component by component. The one Rng passed in drives the init shuffle and every epoch shuffle, so the seed fixes the run.

Step 7, final measures on the trained prototypes over the training rows: a static nearest_two returns the BMU and the second BMU (second-smallest distance, lowest index on ties, same strict < comparison as nearest); qe = mean BMU distance (Euclidean, not squared); te = fraction of rows whose BMU and second BMU are not 4-adjacent, i.e. |dr| + |dc| != 1 (diagonals count as errors, D-04); hits per neuron; occupied_neurons; empty_fraction = 1 - occupied / k^2; mean_hits_occupied = n / occupied (guard occupied > 0); max_hits; singleton_neurons = neurons with exactly 1 hit.
