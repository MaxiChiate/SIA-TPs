## Phase Goal

**As a** campaign analyst, **I want to** run a reproducible C/Python pipeline over an audited, standardized creadores.csv with PCA, **so that** every later result rests on justified variables.

<objective>
Walking skeleton tracer of the C/Python loop: one config.json whose model is oja goes through the single neuron binary into a self-describing, byte-reproducible run directory, and sweep.py turns a multi-seed series of those runs into summary.csv.

Purpose: every later phase (Kohonen, Oja, Hopfield, sweeps, figures) depends on this contract (config mechanism, run directory, metrics.json, summary.csv). Proving it end-to-end first, on one model, catches a wrong contract after one commit instead of after three algorithms.
Output: neuron/ C core (Makefile, rng, vendored cJSON, io/config, io/matrix, io/results, models dispatch, oja stub, main), oja example config and fixture, analysis/sweep.py with its smoke series and README.
</objective>
