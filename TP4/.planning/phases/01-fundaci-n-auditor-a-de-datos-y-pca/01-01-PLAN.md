## Phase Goal

**As a** campaign analyst, **I want to** run a reproducible C/Python pipeline over an audited, standardized creadores.csv with PCA, **so that** every later result rests on justified variables.

<objective>
Walking skeleton tracer of the C side: one config.json whose model is oja goes through the single neuron binary into a self-describing, byte-reproducible run directory; then the config layer is hardened to the strict per-model validation every later config relies on.

Purpose: every later phase (Kohonen, Oja, Hopfield, sweeps, figures) depends on this contract (config mechanism, dispatch, run directory, metrics.json). Proving it end-to-end first, on one model, catches a wrong contract after one commit instead of after three algorithms.
Output: neuron/ C core (Makefile, rng, vendored cJSON, io/config, io/matrix, io/results, models dispatch, oja stub, main), the oja example config and its fixture.
</objective>

## Deviation from locked decision D-05 ("se copia tal cual")

D-05 lists rng.c/h, the Makefile and results.c as copied as-is from TP3. rng.c and rng.h are byte copies (checked with cmp). The Makefile and results.c are copied and adapted, because a verbatim copy cannot satisfy the other locked decisions of the same CONTEXT.md:
- Makefile: ../TP3/neuron/Makefile compiles every source with one CFLAGS that carries -O3, -march=native and three float-reordering flags (CLAUDE.md forbids the reordering flags in TP4 because they break the C-versus-numpy comparisons), has no per-file flags (D-01 requires cJSON compiled without -Wextra/-Wpedantic) and globs activation/ and optimizer/ instead of models/ and vendor/cjson/. Kept verbatim: the variable layout, wildcard SOURCES, the object and dependency rules, -MMD -MP, -include $(DEPS), GNU make 3.81 syntax.
- results.c: TP3 results_create(config_path, activation, results) names the folder {timestamp}_{activation}, and the rest of the file writes and reads MLP weights, predictions, epochs and snapshots that TP4 models do not have. D-04 requires {timestamp}_{model}_seed{N}, and D-05 itself says metrics are rewritten. Kept verbatim: the _POSIX_C_SOURCE line, make_dir, make_run_dir, open_in_run_dir, copy_file.

The executor records this deviation, citing D-05, under Deviations in 01-01-SUMMARY.md. Amending D-05 to "copiar y adaptar" is a user decision outside this plan.
