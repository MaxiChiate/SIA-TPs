Constants VARIANCE_THRESHOLD = 0.80, NULL_EIGENVALUE = 1e-10, BIPLOT_LABELS = 8.

Frozen dataclass PcaResult(features, eigenvalues, eigenvectors, explained, cumulative), eigenvectors as columns. correlation_matrix(z) = z.T @ z / (n − 1) (the prepared matrix is z-scored with ddof = 1, so this is the correlation matrix). pca_eigh(z, features): np.linalg.eigh of the symmetric correlation matrix, sorted by eigenvalue descending, then orient(vectors) flips each column so its largest-magnitude coefficient is positive (the sign convention written in section 5 of the fragment, reused by Phase 3); explained = eigenvalues / sum, cumulative = cumsum. k_by_variance(result, threshold=VARIANCE_THRESHOLD) = smallest k with cumulative >= threshold; kaiser_count(result) = number of eigenvalues > 1 (D-12). scores(result, z) = z @ V; loadings(result) = V * sqrt(max(eigenvalue, 0)) (correlation of each variable with each component); reconstruct(result, s) = s @ V.T. read_prepared(stem) reads datos/prepared/{stem}.csv with the csv module and its {stem}.meta.json, checks the header equals meta features and the row count equals meta n_rows, and returns (features, Z, meta). spearman(a, b) = Pearson correlation of the ranks obtained by argsort of argsort (no ties expected).

main(): apply_style; for each variant (stem creadores_zscore → folder audited; stem creadores_zscore_all31 → folder all31_sensitivity): compute the PCA; write eigenvalues.csv (component, eigenvalue, explained, cumulative), eigenvectors.csv and loadings.csv (variable rows, PC1..PCp columns), scores.csv (creator_id, name, PC1..PCp, using the meta ids and names); plot_scree (bars of eigenvalues, cumulative percentage on a second axis, a horizontal line at eigenvalue 1 labelled Kaiser, a horizontal line at 80 % on the cumulative axis, the k_80 bar highlighted); plot_loadings (heatmap of loadings for PC1..PC{max(k_80, 2)}, DIVERGING, vmin −1, vmax 1, each cell annotated with two decimals); plot_biplot (PC1 vs PC2 scores, each creator coloured by its dominant topic among the four raw topic shares from load_creadores, labels fútbol, maquillaje, perros, arte through palette_for, legend; loading arrows for every variable scaled by s = 0.9 · max |score| / max |loading| with s printed in the subtitle; the BIPLOT_LABELS variables with the largest PC1-PC2 loading norm drawn in TEXT_PRIMARY and labelled, the rest thin in GRID colour without labels; axes "PC1 ({explained:.1f} %)" and "PC2 (…)"); every all31_sensitivity figure title starts with "SENSIBILIDAD (31 columnas, no es el conjunto auditado)"; decision.json with keys variant, n_variables, eigenvalue_sum, k_80, kaiser, rule_agrees, explained_pc1, explained_pc2, cumulative_pc2, null_eigenvalues (count with |eigenvalue| < NULL_EIGENVALUE), min_eigenvalue, top_loadings (for PC1, PC2 and PC3 the 6 variables with the largest |loading|, as [variable, loading] pairs).
